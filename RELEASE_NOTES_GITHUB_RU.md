## Budget Standalone v0.2.0 Stable — Clean Data Edition 💜

Портативное приложение для учёта личного бюджета на Windows 11 x64. Основано на принятой версии v0.2 Stable.

### Возможности
- Учёт доходов, расходов и счетов.
- Категории и отчёты.
- Локальная база SQLite с резервным копированием и восстановлением.
- Тёмное оформление Cinema Mono с золотыми акцентами.
- Плавный старт и обновлённая строка заголовка.

### Конфиденциальность

Архив `Budget_v0.2.0_Stable_Clean_Portable.zip` содержит **обезличенную** демонстрационную базу: 0 операций, 1 пустой счёт, 9 стандартных категорий. Личные финансовые данные не включены.

Исполняемый файл `Budget.exe` совпадает с оригиналом по SHA-256. Архив изменён только в части двух файлов SQLite.

### Установка

1. Скачайте ZIP из раздела Assets.
2. Распакуйте архив в отдельную папку.
3. Запустите `Budget.exe`.

**Статус:** Stable v0.2.0 (обезличенный пакет для публикации).
