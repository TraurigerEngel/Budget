# Budget — безопасность данных в GitHub 💜

Исходный архив проекта содержал пользовательскую базу `data/budget.sqlite3` и её полную копию `seed-data/budget.sqlite3`, включая записи об операциях и счетах.

Для публикации в GitHub:
- Оригинальная рабочая база полностью исключена из отслеживаемых файлов.
- Seed-база заменена обезличенной тестовой БД: 0 операций, 1 стандартный пользователь, 1 счёт с нулевым начальным балансом и 9 общих категорий.
- `data/budget.sqlite3`, резервные копии и журналы SQLite включены в `.gitignore`.
- Исходный исполняемый `Budget.exe` не менялся. Логика приложения также не менялась.

## Запуск после клонирования

1. Запустить `INIT-DEMO-DATA.cmd` для первой установки БД.
2. Установить Node.js 22.13+ и зависимости `npm ci`.
3. Выполнить `npm run verify`.
4. Собрать приложение средствами оригинального проекта, если требуется.

`INIT-DEMO-DATA.cmd` никогда не перезаписывает уже существующую пользовательскую БД. **Не коммитьте приватные SQLite-файлы принудительно (`git add -f`).**

## Releases

Используйте отдельно подготовленный `Budget_v0.2.0_Stable_Clean_Portable.zip`. Он содержит оригинальный неизменённый `Budget.exe` и две одинаковые очищенные базы SQLite.

Этот архив *не совпадает побайтно* с исходным пользовательским релизом, поскольку в нём очищены финансовые данные. Полноценная повторная проверка Windows GUI после изменения стартовых данных остаётся полезной перед распространением.
