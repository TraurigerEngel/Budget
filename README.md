# Бюджет (Budget) 💜

**Budget v0.2.0 Stable — Clean Data Edition**

Портативное приложение для учёта личных финансов на **Windows 11 x64**. Доходы, расходы, счета и отчёты собраны в одном интерфейсе. Данные хранятся локально в SQLite.

**[Скачать готовую версию](https://github.com/TraurigerEngel/Budget/releases/tag/v0.2.0)** · [История изменений](CHANGELOG.md) · [Конфиденциальность](GITHUB_PRIVACY_RU.md)

## Возможности

- Учёт **доходов и расходов**, история операций.
- Работа со **счетами и категориями**.
- **Отчёты** за выбранный период.
- **Резервное копирование и восстановление** локальной базы.
- Тёмная тема *Cinema Mono* с золотыми акцентами.
- Плавный запуск и собственная строка заголовка.

## Установка готовой версии

1. Откройте [релиз v0.2.0 Stable](https://github.com/TraurigerEngel/Budget/releases/tag/v0.2.0).
2. Скачайте файл **`Budget_v0.2.0_Stable_Clean_Portable.zip`** из раздела **Assets**.
3. Распакуйте архив в постоянную папку.
4. Запустите **`Budget.exe`**.

Установка не требуется. **Не удаляйте папку `data`** после начала работы: в ней хранится ваша локальная база. Для переноса приложения сохраняйте данные и резервные копии.

## Конфиденциальность

Этот репозиторий подготовлен **без личных финансовых записей**.

- Рабочая база `data/budget.sqlite3` не включена в Git.
- Файл `seed-data/budget.sqlite3` — обезличенная стартовая база: **0 операций**, один пустой счёт и девять стандартных категорий.
- Личные базы, резервные копии и журналы SQLite исключены правилами `.gitignore`.
- В архиве Clean Portable находится исходный неизменённый `Budget.exe` и очищенные базы данных.

**Не добавляйте собственные файлы `.sqlite3` в коммиты, даже в приватном репозитории.** Подробнее — в [GITHUB_PRIVACY_RU.md](GITHUB_PRIVACY_RU.md).

## Разработка и сборка

Проект использует **Tauri 2, Rust, HTML/CSS/JavaScript и SQLite**.

Для сборки под Windows необходимы Node.js **22.13+**, npm **10+**, Rust с инструментами MSVC и зависимости для сборки Tauri.

После клонирования репозитория откройте PowerShell в папке проекта:

```powershell
# Создать локальную демонстрационную базу, если её ещё нет
.\INIT-DEMO-DATA.cmd

# Установить зависимости и запустить проверки
npm ci
npm run verify

# Собрать отладочную версию
npm run build:dev
```

Отладочная программа появится в `src-tauri\target\debug\budget.exe`. Для интерактивного запуска используйте `npm run dev`.

Для полного релизного цикла сначала установите `cargo-audit` (если его ещё нет), затем запустите:

```powershell
cargo install cargo-audit --locked
.\MAKE-FINAL-RELEASE.cmd
```

**Важно:** `INIT-DEMO-DATA.cmd` не перезаписывает существующую пользовательскую базу. Перед созданием или распространением новой сборки проверьте, что в итоговый пакет не попали личные данные.
